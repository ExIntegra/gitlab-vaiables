    Защита веток требует обновлённых модулей. Их можно скачать в разделе ниже.

    Модули Terraform для защиты веток

    В прежних модулях нет поддержки protected_branches. Этот комплект содержит модули групп, проектов и участников с реализацией защиты веток. Если ваши модули уже поддерживают эти правила, достаточно скачать JSON.

    Как использовать в Terrakube
    1. Выберите «Для Terrakube» и скопируйте JSON.
    2. Создайте Terraform-переменную infrastructure в Terrakube, включите HCL и вставьте значение. Уберите дублирующее значение из файлов tfvars.
    3. Выполните Plan, проверьте изменения и затем Apply.

    Для варианта «Для Terraform без Terrakube» сохраните файл terraform.tfvars.json в корень Terraform-репозитория.

    Родительские группы и пользователи уже должны существовать. Генератор подготавливает файлы; применение выполняется в Terrakube.
